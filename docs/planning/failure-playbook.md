# Failure Playbook — 17 modes (Detection → Mitigation → Fallback → Demo strategy)

1. **pycrdt wheel install failure.** P: low (verified locally 0.14.3) · I: kills live collab. Detect: H0 install. Mitigate: pin versions; manylinux wheels. Fallback: server-authoritative broadcast (presence only, no CRDT claims). Demo: scripted op-replay convergence instead of live typing.
2. **Embedding model download fails.** P: med · I: retrieval degrades. Detect: H0 cache check. Mitigate: pre-download to data/models. Fallback: deterministic hash-embedding + FTS5 banner "degraded". Demo: keyword-only search still shows citations + version filters.
3. **Chroma/onnxruntime install bloat/failure.** P: med · I: vector leg dies. Mitigate: isolated install at H0. Fallback: FTS5-only. Demo: same as #2.
4. **WebSocket instability under two tabs.** P: med · I: collab scene flakes. Detect: H7 two-tab smoke. Mitigate: reconnect backoff, state-vector heal, single uvicorn worker. Fallback: `replay_ops.py` deterministic convergence demo. Demo: narrate convergence proof instead of live typing.
5. **Merge corruption (bad auto-merge).** P: low-med · I: CATASTROPHIC (silent data loss = worst judge outcome). Detect: T1–T8 contract tests + invariant 6 adversarial tests. Mitigate: never auto-merge on any doubt → conflict; merged text rebuildable from inputs. Fallback: force all merges to conflict-review mode. Demo: CLI merge with printed decision trace.
6. **CRDT commit race (commit during active typing).** P: med · I: snapshot inconsistency. Detect: concurrency test. Mitigate: per-artifact asyncio lock; ops during commit land in next commit (documented). Fallback: disable commit-from-live, commit via REST only. Demo: REST commit path.
7. **Parser incompatibility with judge's real export files.** P: med · I: ingest scene fails live. Detect: defensive adapters + warnings. Mitigate: tolerant field lookups, per-file 422s. Fallback: our fixtures (both schemas). Demo: "here's our fixture; your file shape differs in field X — the adapter reports it cleanly."
8. **PDF parse produces garbage/empty text.** P: med · I: PDF beat dies. Detect: ingest warnings. Mitigate: page-structure validation. Fallback: prepared extracted-text fixture. Demo: skip PDF beat, note graceful 422 on image-only.
9. **SQLite lock contention.** P: low (single worker) · I: writes stall. Mitigate: WAL, single writer, short txns. Fallback: retry with backoff. Demo: n/a (invisible at demo scale).
10. **Corrupted object store (disk tamper/crash mid-write).** P: low · I: integrity questions. Detect: `gr verify`. Mitigate: write-temp-then-rename; hash check on read. Fallback: rebuild index from objects. Demo: intentionally corrupt a blob → `gr verify` catches it (planned adversarial beat, high judge value).
11. **Frontend/backend contract mismatch.** P: med · I: UI breaks late. Detect: contract tests from api-contract.md at H6. Mitigate: API-first freeze; AI generates both sides from one spec. Fallback: CLI/scripts demo. Demo: terminal walkthrough (tests as proof).
12. **Sentence splitter edge cases (abbreviations, decimals).** P: high-frequency low-impact · I: ugly diff rows. Mitigate: deterministic documented crudeness; fixtures avoid pathological text. Fallback: paragraph-level diff mode flag. Demo: curated fixtures.
13. **Race: two merge requests same artifact pair.** P: low · I: duplicate pending merges. Mitigate: serialize per artifact pair; return existing merge id. Fallback: 409 + retry. Demo: n/a.
14. **Time runs out (plan slip).** P: HIGH · I: feature loss. Detect: hourly milestone reports vs cut-offs. Mitigate: cut order pre-agreed (12h-execution-plan §0 + hard cut-offs). Fallback: MVP tier only. Demo: MVP script variant (already scripted).
15. **Deployment/demo-env failure (port, venv, machine).** P: med · I: demo blocked. Detect: H12 rehearsal on the actual demo setup. Mitigate: setup.sh + pinned port 8377. Fallback: backup video + live pytest walk. Demo: video + tests.
16. **Awareness/presence flood or ghost users.** P: med · I: presence UI wrong. Mitigate: 30s eviction, 5s heartbeat, cap 3 users. Fallback: hide presence strip; collab still demos. Demo: narrate.
17. **Nondeterminism creeps into diff/merge (dict ordering, timestamps).** P: med · I: exact-output tests flake = demo distrust. Detect: exact-JSON tests from H2. Mitigate: sorted keys everywhere, pinned GR_AUTHOR_DATE, no wall clock in algorithms. Fallback: none acceptable — this is a release blocker by rule.

**Standing rule:** system stays demonstrable if any ONE layer dies; two simultaneous layer deaths → video + tests.
