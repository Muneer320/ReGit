# Ingestion Spec (LOCKED)

Owner: Amrit + AI (adapters). Rule: **parse differently per format, canonicalize per type, never flatten to one string.**

## Adapters

### markdown / plain text
Raw text as-is (canonical = exact bytes). `claim: ...` lines parsed into Claim rows at commit time. kind=md|txt.

### ChatGPT export (`conversations.json`)
Array of conversations; each has `mapping`: msg-id → `{parent, children, message:{author:{role}, content:{parts[], content_type}}}`. Linearize: root (parent==null) → walk children (priority order = children array order; branching preserved as `branches` metadata listing alternate child subtrees). Extract text parts; drop non-text. Volatile (ids, timestamps, key order) EXCLUDED from identity.

### Claude export (zip of JSONL or jsonl)
Each conversation: `chat_messages[]` with `{role, content:[{type:"text",text},{type:"tool_use",…}], timestamp}`. Extract `type=="text"` blocks joined per message; tool_use kept as `[tool: name]` placeholder line. DO NOT assume ChatGPT's schema — separate adapter, separate fixtures, both converge to the canonical form.

### Canonical chat form (shared storage identity)
```
{version:1, source:"chatgpt"|"claude", messages:[{ord, role, text, branches?:[...]}]}
```
Identity = SHA256 over canonical JSON (sorted keys, compact); timestamps stored as metadata but not hashed → re-export of the same conversation dedups to the same blob.

### PDF
`pypdf` per page → `{pages:[{n, paragraphs:[...]}]}` (blank-line split). Image-only → 422 PDF_NOT_EXTRACTABLE (graceful). OCR = out of scope.

### Codebase
Path: git repo dir or zip. Walk files (skip .git, binaries, >1MB) → per-file blobs + tree. Primary semantic language: Python; others line-diff fallback.

## Universal pipeline
`upload → adapter.parse → canonical payload → ResearchSource row + Artifact row + imported_as/has_version/in_commit edges → root commit → initial chunking+index`.
Warnings array surfaces partial issues (skipped binary files, non-text chat parts). Defensive field lookups everywhere; unknown shapes → 422 with a specific message, never a traceback.

## Fixtures (scripts/fixtures/)
`notes.md` (with 2 `claim:` lines), `chatgpt_export.json`, `claude_export.jsonl`, `paper.pdf` (small text PDF), `codebase/` (tiny Python pkg) + merge triple `merge/{base,ours,theirs}.md` + diff pairs. All fixtures deterministic; regenerated by `scripts/make_fixtures.py` if formats drift.

## Tests (tests/unit/test_ingest.py)
Both chat schemas → same canonical shape; same chat re-exported with different ids → same blob id; pdf page structure preserved; codebase tree hash stable; claim sentinels parsed; malformed uploads → 422 not 500.
